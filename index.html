Fuel Log App

An app for recording refuels and fuel economy for a motorcycle, built with an Expo (React Native) client and a NestJS API. It uses JWT access and refresh tokens (refresh tokens are stored hashed in Redis), caches monthly stats in Redis, and rate-limits requests with a Redis-backed throttler. GitHub Actions runs the tests and an end-to-end API smoke test.
